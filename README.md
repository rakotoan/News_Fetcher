# 📰 Financial News Report Generator

Welcome to the Financial News Report Generator project ! This application is designed to **collect financial news articles** from NewsAPI using custom **keywords** and **time filters**. It then organizes the results into a formatted Excel report to support market monitoring, research, and daily news tracking.


## ⚙️ Prerequisites

To successfully run this project, ensure you have the following installed:
- 🐍 **Python**
- 📦 **Required libraries:**
  - `newsapi`
  - `openpyxel`


## 📌 Installation
 
1. Create and activate a Python virtual environment.
2. Install dependencies
3. Get a NewsAPI key from [NewsAPI](https://newsapi.org/)


## 💻 Usage

To launch the application, run:

```bash
python app.py
```
